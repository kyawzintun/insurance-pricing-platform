# Architecture Decision Records

Use this directory to record approved architecture decisions as they are documented.

Naming convention: `ADR-001-short-title.md`, using a sequential number and a concise descriptive title. An ADR can record its status, context, decision, and consequences.

The approved high-level constraints are preserved in [architecture.md](../architecture.md). No individual ADRs are created in Phase 0 because no approved ADR documents have been supplied.
